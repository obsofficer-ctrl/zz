# Prerequisites

Before you can use ZZ, you need a few tools installed on your system.

## Required

### A C Compiler

ZZ compiles to plain C and then invokes a C compiler to produce a binary. You need one of the following:

- **GCC** (recommended for Linux)
- **Clang** (recommended for macOS)
- Any ANSI C-compatible compiler for your target platform
