# Z3 & Yices

ZZ uses SMT (Satisfiability Modulo Theories) solvers to perform formal verification. It supports two solvers: Z3 and Yices.

## Z3

[Z3](https://github.com/Z3Prover/z3) is the default solver used by ZZ. It is developed by Microsoft Research and is widely used in program verification tools.
